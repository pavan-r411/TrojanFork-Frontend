# TrojanPlate visual system

Reference: the latest user-supplied onboarding, Home, My Plan, nutrition and profile screenshots. These supersede the earlier Claude.pdf dark palette while preserving existing behavior and live data contracts.

- Warm ivory background #f7f4ef; white surfaces; raised taupe #eee8e3; borders #e6dfd9.
- Main text #292622; secondary #827b73; burgundy #872c40; deep wine #4b1d2b; blush #f0e0e4; gold #d4ac5e; soft sage supporting panels.
- Outfit is the display/body family, with readable mobile typography and clear heading hierarchy.
- Mobile app shell with 20px content edges; from 768px the layout expands to a 1160px workspace, with a sticky plan sidebar from 1024px; existing Home, My Plan, profile/setup and dining tabs remain functional.
- White rounded meal cards, burgundy gradient nutrition panels and primary actions, gold calorie arc, sage carbohydrate progress and white floating navigation with a burgundy active tab.
- Local food illustrations are MIT-licensed Microsoft Fluent Emoji PNG assets. Decorative art has empty alt; real backend food images remain supported.
- Subtle progress, swipe, button and loading animations respect reduced-motion preferences.
- Unknown data stays unknown, estimates stay labeled, and selecting never logs a meal as eaten.
